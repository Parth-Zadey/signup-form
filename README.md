## 📌 About the Project

This is a **mock project/assignment provided as part of frontend development practice**.

The project is a simple and interactive **Signup Form** created using **HTML, CSS, and JavaScript**, based on the provided Figma design reference. It focuses on implementing form validation, JavaScript event handlers, user interaction, and a clean and simple user interface.

The main purpose of this project was to practice **HTML form structure, CSS styling, JavaScript event handling, input validation, DOM manipulation, conditional logic, confirmation dialogs, alerts, and website deployment using GitHub Pages**.

---

## ✨ Features

- 📧 Email validation
- 🔐 Password validation
- ⚠️ Red error messages for invalid inputs
- ✅ Green success message when all inputs are valid
- 🔄 Validation using `change` event handlers
- 📝 Confirmation window before signup
- 🎉 Successful signup alert
- 🔃 Page reload and input clearing when signup is cancelled
- 📱 Responsive layout
- 🎨 UI based on the provided Figma design

---

- **CSS3**

## 📋 Validation Rules

### 📧 Email

The email is considered valid when:

- It contains more than 3 characters
- It contains `@`
- It contains `.`
